# Mohsin-Taylors
Mohsin Taylors - Official Website
A modern, responsive, and catchy landing page for Mohsin Taylors, a premium bespoke tailoring shop located in Havelian Cantt. This project features a clean "Taylor" aesthetic with animated interactions and bilingual support (English & Urdu).

🛠️ Features
Animated Booking System: A high-energy, "bounce-in" modal alert that displays shop contact details and location upon interaction.

Bilingual Content: Integrated Urdu (Noto Nastaliq) and English text to cater to the local community in Havelian.

Interactive Service Menu: A dynamic price list covering normal stitching, fancy suits, and repairs, with hover-effects for engagement.

Process Flow: A visual "How it Works" section inspired by modern tailoring service standards.

Responsive Design: Fully optimized for mobile, tablet, and desktop views.

Direct CTA: Integrated "Visit Us" and "Book Now" buttons that prioritize immediate customer contact.

🚀 Tech Stack
HTML5: Semantic structure.

CSS3: Custom animations (Pulse, BounceIn) and grid/flexbox layouts.

JavaScript (ES6+): Dynamic DOM manipulation for the service menu and modal logic.

Google Fonts: Noto Nastaliq Urdu and Poppins for professional typography.

FontAwesome: High-quality vector icons for process steps.
